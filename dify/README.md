# Dify 对话流

`app.yaml` 是对话流的完整导出，包含 50 个节点：10 个代码节点、6 个知识检索、6 个解读模型、
6 个判断分支、10 个变量赋值。

## 怎么导入

1. Dify 首页 → **导入应用**（或「创建空白应用」旁的导入入口）
2. 选择 `app.yaml`
3. 导入后会生成一个 **Chatflow（advanced-chat）** 类型应用

> 注意：导出文件里**不含任何 API Key**。Dify 的密钥存在它自己的数据库里，不进 DSL。
> 所以导入后需要你自己配置模型供应商。

## 导入后必须做的三件事

**一、配置模型供应商**

每个 LLM 节点（六个解读 + 问题分类器 + 两个参数提取器）都要重新选模型。
在「设置 → 模型供应商」里配好（DeepSeek / 通义 / OpenAI 都行），然后逐个节点检查。

**二、建六个知识库**

对话流里有六个 `knowledge-retrieval` 节点，分别对应八字、六爻、塔罗、黄历、星座、紫微。
导入后这些节点的知识库引用是空的，需要你自建并重新绑定。

内容建议：
- 塔罗：78 张牌的牌义（正位 / 逆位）
- 六爻：64 卦卦辞与爻辞
- 八字：十神、五行生克
- 紫微：十四主星性质、十二宫含义
- 黄历：建除十二神的宜忌
- 星座：十二星座性格与元素

**三、检查开始节点**

开始节点有五个输入变量（`lunar_year`、`lunar_month`、`lunar_day`、`hour_index`、`gender`），
都是可选的。其中 `gender` 被「紫薇换算」节点使用，其余四个目前没有节点引用——
农历参数实际是从用户那句话里提取的。

## 节点结构

```
开始 → 提取关键字 → 输出加固判断 → 判断数据
                                    ├→ 问题分类器 → 六个起盘分支
                                    ├→ 参数提取器（八字）
                                    ├→ 参数提取器-紫薇
                                    └→ 外部循环（判断）
起盘 → 变量赋值 → 判断卦 → 知识检索 → 解读 → 变量聚合器
     → 格式转换 → 拉去历史记录 → 变量赋值-历史 → 直接回复
```

## 十个代码节点

| 节点 | 作用 |
| --- | --- |
| 输出加固判断 | 读会话变量，决定补参 / 追问 / 交给分类器 |
| 提取关键字 | 关键词匹配，判断主题 |
| 操牌 | 塔罗抽三张，seed 落盘 |
| 操卦 | 六爻投币，定本卦变卦 |
| 转换日历 | 八字四柱 |
| 紫薇换算 | 紫微命盘 |
| 黄历计算 | 建除十二神与宜忌 |
| 星座计算 | 太阳星座 |
| 拉去历史记录 | 追加历史，只留最近 5 轮 |
| 格式转换 | 剥掉聚合器的包装层 |

代码节点的源码也单独导出在仓库同级的 `dify_dsl/code/` 里（如有需要可另存）。
